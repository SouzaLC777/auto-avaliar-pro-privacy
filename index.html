Política de Privacidade

Privacidade em Primeiro Lugar: O Auto Avaliar Pro opera 100% no seu computador (client-side). Não possuímos servidores de coleta de dados e nenhuma informação sua é vendida, repassada ou transmitida para terceiros.

1. Informações Processadas e Finalidade

Para executar suas funções de automação e melhoria de interface na plataforma autoavaliar.com.br, a extensão faz uso dos seguintes dados:

  • Credenciais de Acesso (E-mail e Senha): Utilizadas exclusivamente pelo módulo de Manutenção de Sessão / Login Automático para renovar a sessão do usuário de forma transparente quando o token do sistema expira.
  • Preferências de Interface: Opções de tema escuro, layout do painel FIPE e estado dos seletores de desempenho.
  • Cache de Templates: Dados de renderização guardados para acelerar o carregamento de páginas.

2. Armazenamento de Dados

Todos os dados processados — incluindo e-mail e senha informados pelo usuário — são armazenados estritamente de forma local no seu navegador por meio da API oficial do Google Chrome (chrome.storage.local).

  • Não há tráfego de credenciais para endpoints externos.
  • O envio de dados de autenticação ocorre estritamente entre o seu navegador e a API oficial do autoavaliar.com.br.

3. Bloqueio de Rastreadores e Telemetria

A extensão possui um recurso nativo para bloquear scripts de telemetria e rastreamento de terceiros (como Google Analytics, Facebook Pixel, Google Tag Manager e Powerbiz) dentro do domínio do Auto Avaliar, visando aumentar o desempenho e reforçar a privacidade da sua navegação.

4. Permissões do Navegador

As permissões solicitadas no manifesto da extensão (como storage e declarativeNetRequest) são utilizadas estritamente para salvação local de preferências e execução das regras de bloqueio de rede para melhoria de desempenho.

5. Contato e Suporte

Dúvidas ou solicitações relacionadas ao funcionamento da extensão e ao tratamento local de dados podem ser encaminhadas ao desenvolvedor responsável (Gustavo Soares / Logic Org).
